# design/

Design assets for Shidi, added by Rishabh as the design-track milestone (D)
completes.

Expected contents:

- `flows/` — flow diagrams for the 9 flows (PRD-design §5)
- `wireframes/` — low-fi screens, including keyboard-open variants
- `prototype.md` — link/export of the clickable prototype (the two make-or-break interactions)
- `components/` — component specs with all states (PRD-design §7)
- `tokens.md` — design tokens: type ramp, colour semantics, spacing, motion
- `microcopy.md` — final copy for every moment (PRD-design §8)

Contract for engineers: UI tickets build functional-first against placeholder
tokens in `src/styles/tokens.css`. When assets land here, the "Design alignment
pass" ticket applies them everywhere. If a mockup exists for your screen when
you pick a ticket, follow it.
