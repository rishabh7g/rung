BRAND — RATIFIED
  • rung — the unit the product is built on: one checkpoint, one step. शिडी was Marathi-bound; with courses the name must outlive any one language. Four letters, lowercase, plain-English meaningful.
  • Mark: two rails + three rungs, middle rung solid accent — "you are here". Drawn in the blueprint grammar: hairline, square, registration-mark-compatible.
  • Alternates if it doesn't land: Paydan (पायदान — Hindi for rung; warmer, but L1-tied again) · Climb (verb energy, more generic). One caution to test with P1: a Hindi ear may hear "rung" as रंग (colour).
NEW: COURSES, NOT A TOGGLE
  • Course = one L1→L2 pair (hindi→marathi, english→spanish). One active at a time; Settings → COURSE switches.
  • Nothing is erased: every course keeps its own ladder, production counters and review queue. Switch away mid-M3, switch back — still 16/20.
  • Microcopy travels with the course, not the shell: the Hindi nudges, ritual copy and cue labels are course content — the Spanish course speaks English because its L1 is English. Engineering: nudge/ritual strings move into the course bundle.
  • The engine (levels, seal rule, reveal practice, ritual, retry) is untouched — proof the ladder generalises.
  • Spanish here is a 4-sentence M1 sample to prove the seam; real authoring waits until Marathi L1 proves out (native gate per course).
  • Speech-first script policy (Rishabh): a course whose script doesn\u2019t transfer runs romanized-first — Arabic shows "ismī Rohān" as the primary line, the script kept as one quiet secondary line for recognition (not required reading). Devanagari courses stay native (the script IS free transfer from Hindi). PRD: per-course scriptMode flag + romanization field in the sentence schema.
  • Rung card sequenced (team review): fresh rung → one CTA, "Start with the module"; once studied → Practice primary + quiet "revisit the module"; production done → Exit ritual primary; pending rung → note only. Guides the order (read → practice → exit) without gating — the Practice tab stays reachable, per Invariant "phases guide, never gate".
PRD IMPLICATIONS (FOR RISHABH)
  • State: key progress by courseId — {activeCourse, courses:{'hi-mr':{…}}}; stateVersion bump; export carries all courses.
  • Content manifest gains a course layer; delta/interference tags are pair-specific by definition.
  • Invariants unchanged and course-agnostic (no time framing, no inputs, learner checks).
  • Recommend: ship the schema seam in v1, ship ONE course. Course #2 is a content project, not an app project.
DEMO PATH
  1. Settings → COURSE → tap english → spanish: ladder shows its own fresh state, M1 current, English microcopy throughout (module, practice, ritual).
  2. Switch back to hindi → marathi: M3 untouched at 16/20 — nothing erased.
  3. Everything from v3.2 still demos: जांचो guidance step, hold-to-confirm, comprehension retry, unlock beat.
